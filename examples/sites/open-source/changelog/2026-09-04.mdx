### Features

- Retention policies per series with `set_retention`. Old blocks are dropped in the background.
- New `driftdb` CLI with `stats`, `export` and `compact` commands. Install it with `cargo install driftdb-cli`.
- Appends are about 2x faster thanks to a lock-free write buffer.

### Fixes

- Opening a database on a read-only filesystem now returns an error instead of panicking.
