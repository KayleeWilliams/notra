### Breaking

- New on-disk format v2. 0.9 opens 0.8 files read-only until you run `driftdb migrate`. See [why we changed it](/blog/on-disk-format-v2).
- `Series::query` is renamed to `Series::range`. The old name is removed, not deprecated.
- Minimum supported Rust version is now 1.85.

### Features

- Block checksums. A corrupted block is skipped and logged instead of failing the query.
- Write-ahead index, so recovery after a crash takes under a second.
- Python wheels for 3.13 on Linux, macOS and Windows.

### Fixes

- `downsample` no longer drops the last bucket when the range ends exactly on a bucket boundary.
