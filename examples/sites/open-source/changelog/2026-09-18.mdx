### Fixes

- Fixed a race where compaction and a concurrent `append` could write the same block twice. Thanks to @mhollis for the reproduction.
- Retention now drops the oldest block too, instead of keeping one block past the limit.
- `driftdb stats` reports compressed size correctly on Windows.
