DriftDB runs inside your process, like SQLite. There's no server to start and no port to open. This guide gets you from an empty project to a downsampling query.

## Install

In a Rust project, run **{{ install }}**. For Python, the bindings are on PyPI as `driftdb`.

## Write and query

<Tabs>
  <Tab title="Rust">
    ```rust
    use driftdb::{Db, Duration};

    let db = Db::open("./data")?;
    let temp = db.series("greenhouse.temp")?;

    temp.append(now(), 21.4)?;

    let hourly = temp
        .range(Duration::days(1))
        .downsample(Duration::hours(1))
        .avg()?;
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import driftdb

    db = driftdb.open("./data")
    temp = db.series("greenhouse.temp")

    temp.append(driftdb.now(), 21.4)

    hourly = temp.range(days=1).downsample(hours=1).avg()
    ```
  </Tab>
</Tabs>

## Keep only what you need

Most sensor data loses value fast. Set a retention policy per series and DriftDB drops old blocks in the background:

```rust
temp.set_retention(Duration::days(90))?;
```

<Tip>
  Downsample before you drop. A rollup series with hourly averages takes about 1% of the space of the raw data and keeps the long-term trend.
</Tip>
