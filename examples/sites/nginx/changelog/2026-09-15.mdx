- The chunk index loads lazily, so an incremental run on a 10 million file share starts in 40 seconds instead of 3 minutes
- New `sb stats --sets` shows the deduplication ratio per backup set
- Fixed SFTP targets dropping the connection after 2 hours on servers with a short `ClientAliveInterval`
- Fixed Windows agents skipping files with names longer than 260 characters
