- **Restore tests** per backup set, on a weekly schedule you pick
- Database sets restore one table and compare its checksum
- Failed tests alert the same channels as failed backup jobs
- New **Reports → Restore tests** page with the last 12 weeks of results

<Note>
  Restore tests read from your targets, so they add egress on cloud storage. See the [announcement](/blog/scheduled-restore-tests) for numbers.
</Note>
