Archive imagery tells you what a place looked like. Sometimes you need to know what it looks like on Thursday. That used to mean an email to a sales team and a PDF order form. Now it is one request.

## Order a capture

Send a point or polygon, a time window and the maximum cloud cover you will accept:

<Tabs>
  <Tab title="curl">
    ```bash
    curl https://api.orbitly.dev/v3/tasks \
      -H "Authorization: Bearer $ORBITLY_KEY" \
      -d '{"aoi": [-122.4194, 37.7749], "window": "P3D", "max_cloud": 0.1}'
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from orbitly import Orbitly

    client = Orbitly()
    task = client.tasks.create(aoi=(-122.4194, 37.7749), window="P3D", max_cloud=0.1)
    print(task.id, task.earliest_pass)
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { Orbitly } from "@orbitly/sdk";

    const orbitly = new Orbitly();
    const task = await orbitly.tasks.create({ aoi: [-122.4194, 37.7749], window: "P3D", maxCloud: 0.1 });
    ```
  </Tab>
</Tabs>

The response includes `earliest_pass`, the first time one of our satellites can see your point, usually within 18 hours.

## Get told when it lands

Add a webhook and we call it once the image is processed and ready to download:

```json
{
  "type": "task.completed",
  "task_id": "tsk_8f2k1q",
  "scene_id": "orb_20260918_1042_s07",
  "cloud_cover": 0.04
}
```

If the window closes without a clear shot, you get `task.expired` and you are not charged.

## Pricing

A task costs the same as 25 km² of archive imagery, with a minimum area of 25 km². See the pricing page for volume rates.
