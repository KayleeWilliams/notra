SDK 3.0 is out for Unity and Godot. It's the first release where both engines share the same API, so an event tracked in one looks the same in the other.

## Install

<Tabs>
  <Tab title="Unity">
    Add the package by Git URL in the Package Manager:

    ```text
    https://github.com/cadence-games/cadence-unity.git#3.0.0
    ```
  </Tab>
  <Tab title="Godot">
    Copy `addons/cadence` into your project and enable **Cadence** under **Project → Plugins**.
  </Tab>
</Tabs>

## Track an event

<Tabs>
  <Tab title="Unity">
    ```csharp
    Cadence.Track("level_complete", new { level = 12, stars = 3 });
    ```
  </Tab>
  <Tab title="Godot">
    ```gdscript
    Cadence.track("level_complete", { "level": 12, "stars": 3 })
    ```
  </Tab>
</Tabs>

## Offline batching

Phones lose signal on the subway and the OS kills games in the background. 3.0 writes events to disk before it sends them, in batches of up to 50. If the game is killed mid-send, the batch goes out on the next launch. In our tests on a Pixel 6a, we lost 0 of 100,000 events across 2,000 forced kills.

## Smaller build

The Unity package now adds 180 KB to an Android build, down from 610 KB, because we dropped the JSON library and use Unity's own serializer.

<Note>
  2.x keeps getting security fixes until March 2027. Event names and properties are unchanged, so upgrading is a package bump.
</Note>
