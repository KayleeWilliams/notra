Pixelmint has 1,840 icons now, and the most common support question is "do you have one for X?". The answer is usually yes, under a name you didn't guess. So we put a search box right here in the post. <Badge>New</Badge>

## Try it

Search by name or by what the icon means. "weather" finds the sun, moon and cloud. "plant" finds the leaf and the sprout. Click an icon to preview it at 16, 24, 32 and 48 pixels, then click the tag under the preview to copy it.

<IconSearch initial="sprout" />

This box is a React component from `snippets/icon-search.jsx`. It holds 16 icons so the page stays light. The full catalog search on our docs uses the same code with all 1,840.

## Copy a name from anywhere

Icon names in our posts are buttons now. Click <IconName name="sprout" client:static /> or <IconName name="sparkles" client:static /> and the name lands on your clipboard, with a small toast to confirm it.

<Tip>
  These buttons render with `client:static`, so the page ships no JavaScript for them. One `script.js` file listens for clicks on anything with a `data-copy` attribute, including the tag in the search box above.
</Tip>

## Install

<Install version="3.2" feature="the size and stroke props" />

Then use an icon like any other component:

<CodeGroup>
```tsx
import { SproutIcon } from "@pixelmint/react";

<SproutIcon size={24} stroke={1.5} aria-label="Plant growth" />
```

```vue
<script setup>
import { SproutIcon } from "@pixelmint/vue";
</script>

<template>
  <SproutIcon :size="24" :stroke="1.5" aria-label="Plant growth" />
</template>
```
</CodeGroup>

<Note>
  Icons are decorative by default and get `aria-hidden="true"`. Pass `aria-label` when the icon is the only thing that says what a button does.
</Note>

## Keyboard

The search box works without a mouse. Press <Kbd client:static>Tab</Kbd> to move to an icon and <Kbd client:static>Enter</Kbd> to preview it. On our docs, <Kbd client:static>/</Kbd> jumps straight to the search field.
