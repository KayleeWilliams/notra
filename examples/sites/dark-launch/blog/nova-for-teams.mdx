Notes are only useful if they end up where the work happens. The last launch of the week is about getting them there.

## Shared workspaces

A workspace holds your team's meetings, templates and integrations in one place. Anyone in the workspace can open notes from shared meetings, and Ask searches all of them.

Admins decide which meetings are shared by default: all of them, only meetings with people outside the company, or none.

## Templates per team

Sales calls need next steps and objections. Standups need blockers. Each team now picks a template, and Nova writes notes in that shape.

<CardGroup cols={3}>
  <Card title="Sales call">Pain points, objections, budget, next step.</Card>
  <Card title="Standup">Done yesterday, planned today, blockers.</Card>
  <Card title="Interview">Signals per question, overall take, follow-ups.</Card>
</CardGroup>

## The Nova API

Every meeting is available as JSON a few seconds after it ends. Register a webhook, and Nova calls it with the summary, decisions and action items:

<Tabs>
  <Tab title="Register a webhook">
    ```bash
    curl https://api.nova.ai/v1/webhooks \
      -H "Authorization: Bearer $NOVA_API_KEY" \
      -d url=https://example.com/hooks/nova \
      -d events=meeting.notes_ready
    ```
  </Tab>
  <Tab title="Payload">
    ```json
    {
      "event": "meeting.notes_ready",
      "meeting": {
        "id": "mtg_8f2k1",
        "title": "Halden weekly",
        "duration": 1840
      },
      "actionItems": [
        {
          "owner": "ines@nova.ai",
          "text": "Send the CSV export spec",
          "at": 1312
        }
      ]
    }
    ```
  </Tab>
</Tabs>
