Most of our clients publish long texts: research notes, essays, annual reports. Here is the type setup we start from before any brand work.

## The defaults

| Setting | Value | Why |
| --- | --- | --- |
| Body size | 18px | Comfortable on laptops without zooming |
| Line height | 1.6 | Enough air for 65 characters per line |
| Measure | 34rem | About 65 characters in most serif faces |
| Paragraph spacing | 1em | One blank line, no indents |
| Headings | Same family, heavier weight | Fewer fonts to load |

This journal uses a narrow single column for the same reason. There is no sidebar competing with the text.

## The three we change most

- **Measure.** Sans-serif faces run wider, so we drop to 32rem.
- **Line height.** Large x-height fonts like Inter need less, around 1.5.
- **Body size on phones.** We keep 17px instead of shrinking to 16px. The difference is small, the reading comfort isn't.

<Tip>
  Test with real text from the client, not lorem ipsum. Real paragraphs have long words, numbers and footnotes that break a tidy layout.
</Tip>
