title: "forge dev with hot reload"
date: 2026-08-05
version: "v2.4.0"
description: "forge dev now reloads tools in place when you save, without losing form state."
tags: [Feature]
---

`forge dev` watches your tool folder and reloads the changed module in the running preview. Form inputs, selected table rows and open drawers stay as they were.

```bash
forge dev ./tools/refunds --port 4310
```

- Reloads in under 200 ms for most tools
- Changes to `forge.config.ts` restart the dev server instead of hot reloading
- `--no-hmr` turns it off if a tool keeps global state that doesn't survive a reload
