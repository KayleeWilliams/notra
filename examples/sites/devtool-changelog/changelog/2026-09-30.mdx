<Warning>
  This release has breaking changes. Run `forge migrate` before you deploy, and read [the upgrade guide](/blog/upgrading-to-forgekit-3) for the details.
</Warning>

## Breaking

- `forge.json` is no longer read. Settings move to `forge.config.ts`
- Node 18 is no longer supported. Forgekit needs Node 20.11 or later, or Bun 1.2
- `ctx.user.roles` is now `ctx.user.groups`, to match how SSO providers name them

## New

- `forge migrate` rewrites `forge.json` into `forge.config.ts` and renames `ctx.user.roles` in your actions
- `defineConfig` gives you autocomplete for every setting

## Upgrade

Run the migration, then check the generated config:

```bash
npx forgekit@3 migrate
```

```typescript
// forge.config.ts
import { defineConfig } from "forgekit";

export default defineConfig({
  name: "ops-tools",
  auth: { provider: "okta", groups: ["support", "finance"] },
});
```
