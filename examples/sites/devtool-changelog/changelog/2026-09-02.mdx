`defineAction` takes a Zod or Valibot schema and infers the input type in the UI and the handler. No more hand-written types that drift.

```typescript
import { defineAction } from "@forgekit/sdk";
import { z } from "zod";

export const refundOrder = defineAction({
  input: z.object({ orderId: z.string(), amountCents: z.number().int() }),
  async run({ input, db }) {
    return db.refunds.create({ data: input });
  },
});
```

- Inputs are validated on the server before `run` is called
- Validation errors show next to the matching form field
