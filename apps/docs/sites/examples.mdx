Every example is a complete site folder in [`examples/sites`](https://github.com/usenotra/notra/tree/main/examples/sites) of the Notra repository, with its own `blog.json`, posts, changelog and a README that lists what it shows. Examples served under a path also have a small app or config for the main website in [`examples/hosts`](https://github.com/usenotra/notra/tree/main/examples/hosts).

To start from one, copy its folder into your repository and create a site from it under **Sites → New site**. If the folder isn't at the root of the repository, turn on **Site is in a subdirectory** and enter its path.
